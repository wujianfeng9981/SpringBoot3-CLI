会议室预约管理系统

Spring Boot 3.4.x + MyBatis Plus + MySQL + Redis

会议室管理

POST /api/meeting-room/add 添加会议室
POST /api/meeting-room/update 更新会议室
POST /api/meeting-room/delete 删除会议室
GET /api/meeting-room/get 获取会议室详情
POST /api/meeting-room/list/page 会议室分页列表

预约管理

POST /api/meeting-booking/add 创建预约（自动校验冲突）
POST /api/meeting-booking/update 更新预约
POST /api/meeting-booking/cancel 取消预约
GET /api/meeting-booking/get 获取预约详情
POST /api/meeting-booking/list/page 预约列表分页

审批流程

POST /api/booking-approval/approve 审批预约（通过/驳回）
GET /api/booking-approval/get 获取审批详情
POST /api/booking-approval/list/page 审批列表分页

会议签到

POST /api/meeting-checkin/add 签到
GET /api/meeting-checkin/get 获取签到详情
POST /api/meeting-checkin/list/page 签到列表分页
GET /api/meeting-checkin/statistics 会议室使用统计

通知系统

POST /api/meeting-notification/read 标记通知为已读
GET /api/meeting-notification/get 获取通知详情
POST /api/meeting-notification/list/page 通知列表分页
